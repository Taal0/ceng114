Final Project

Project Overview

The final project is a comprehensive programming assignment that integrates all concepts learned throughout the semester. Students will design and implement a complete program that demonstrates their understanding of:

  • Problem decomposition and algorithm design
  • Effective use of functions and modular programming
  • Proper use of data structures (arrays, strings)
  • Input validation and error handling
  • Code documentation and style

Important Dates

Milestone Date
Project Released December 1, 2025
Project Proposal Due December 5, 2025
Final Submission December 12, 2025

Detailed project specifications will be released on December 1st.

Submission Guidelines

  • All code must be well-commented and follow proper coding style conventions
  • Include your name, student ID, and assignment number at the top of each file
  • Test your code thoroughly before submission
  • Submit source code files (not compiled executables)
  • Include a README file if multiple files are submitted
  • Follow file naming conventions: lastname_firstname_assignmentX.ext
