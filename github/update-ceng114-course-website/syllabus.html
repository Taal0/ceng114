Course Description

CENG114 is an introductory course in computer programming designed for students with little or no prior programming experience. The course covers fundamental programming concepts, problem-solving techniques, and algorithm development using a high-level programming language. Students will learn to write, test, debug, and document programs while developing computational thinking skills.

Prerequisites

None. This course assumes no prior programming experience.

Learning Objectives

By the end of this course, students will be able to:

  • Understand and apply fundamental programming concepts including variables, data types, operators, and expressions
  • Use control structures (conditionals and loops) to create program logic
  • Design and implement functions for modular programming
  • Work with arrays and strings to manage collections of data
  • Apply basic algorithms for searching, sorting, and data manipulation
  • Debug and test programs systematically
  • Write clear, well-documented code following best practices
  • Solve computational problems through algorithmic thinking

Course Policies

Attendance

Regular attendance is expected. Missing more than three classes may affect your participation grade.

Late Work

Assignments submitted late will incur a 10% penalty per day, up to a maximum of 3 days. After 3 days, assignments will not be accepted unless there are extenuating circumstances.

Academic Integrity

All work submitted must be your own. Collaboration is encouraged for learning, but submitted work must be independently completed. Plagiarism or cheating will result in serious academic consequences.

Accommodation

Students requiring accommodations should contact the instructor during the first week of class to discuss their needs.

Topics Covered

  • Introduction to Programming and Computational Thinking
  • Variables, Data Types, and Operators
  • Input/Output Operations
  • Conditional Statements (if, else, switch)
  • Loops (for, while, do-while)
  • Functions and Parameter Passing
  • Arrays and Strings
  • Basic Algorithms (Searching and Sorting)
  • Introduction to Data Structures
  • File I/O
  • Debugging and Testing Techniques
