Development Tools

You will need to install the following software for this course:

  • Integrated Development Environment (IDE)
    Choose one of the following:
    • Visual Studio Code (Recommended) - Free and cross-platform
    • Eclipse - Popular for Java development
    • PyCharm - Excellent for Python development
    • Code::Blocks - Lightweight C/C++ IDE
  • Compiler/Interpreter
    Depending on the programming language used in class (Python, Java, C++, etc.)
  • Version Control
    Git - Essential for managing your code and submissions
