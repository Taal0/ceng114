Course Description
This course is a continuation of CENG113 (Introduction to Programming 1) and covers sorting and searching
algorithms, recursion, and object-oriented programming (OOP) in Java, focusing on fundamental principles
such as encapsulation, inheritance, polymorphism, abstract classes, interfaces, exception handling, and
text/binary I/O. The course further explores generics, data structures (lists, stacks, queues, linked lists), and
introduces event-driven programming. By the end of the course, students will be able to design, implement,
test, and document medium-scale software applications following object-oriented design principles.
